# 국장 인트라데이 급등추격 — 검증 결과 (2026-06-02)

## 질문
"갑자기 상승하는 종목을 점화 순간에 포착해 연속성(continuation) 먹는다" — 거래대금
share-velocity 리더가 forward H분 아웃퍼폼하는가?

## 데이터
- KIS `minute_chart_by_date` (TR FHKST03010230): 1분봉 by-date **lookback ≥ 1년** 실측
  (T-365=20250602도 120봉 정상 반환). 저장 데이터 0 — 라이브 API on-demand.
- 검증: 최근 32거래일(20260420~0602), 거래대금 top-30, share-velocity top-5 리더,
  결정점 10분 step, (L,H) 그리드.

## 수정한 버그 (intraday_check.rs)
1. **진입가 lookahead** — 기존: 신호 확정 시점 t의 가격에 진입(t분 봉 내 모멘텀 공짜
   포획). 수정: `INTRADAY_ENTRY_LAG`(기본 1) → t+1봉 진입(라이브 추격 현실).
2. **비용 누락** — `INTRADAY_COST_BPS`(기본 50) → `net% = lead% − cost` 컬럼 추가.
   2026 거래세 매도 0.20%(코스피 0.05%+농특세0.15% / 코스닥 0.20%) + 슬리피지.

## 결과 — 엣지 없음, 정반대로 손실
entry_lag=1, cost=50bps, 32일:

KOSDAQ(KSQ): lead% 전 셀 **음수** -0.47~-2.37%, excess t = **-4.2 ~ -12.3**, hit 30~41%
KOSPI(STK):  lead% 전 셀 **음수** -0.16~-1.18%, excess t = **-2.2 ~ -7.1**, hit 37~46%

- 비용 전(lead%)에도 전부 음수 → 추격 진입시 엣지 0.
- share급등 리더가 유니버스보다 체계적 underperform(t 압도적 음수) = **인트라데이
  평균회귀**. "급등 사면 물린다" 교과서.
- 거울상(급등 fade=숏)은 강한 신호지만 코스닥 스몰캡 대차제약/업틱룰로 롱온리 불가.

## 레짐 맥락 (중요)
KOSPI 5월초 7,000 → 5월말 ~8,800, 사상최고, 반도체 주도 **포물선 멜트업**(+25%/월,
삼성+436%/하이닉스+1000% YoY). **다 오르는데도** 급등추격 손실 — 신호 진짜 약함 입증.
멜트업 상승은 갭/초반 주도, 장중 드리프트는 평평~음수(univ% 음수가 증거).

## 결론
- 인트라데이 share-velocity 급등추격 = 양 시장·강세장 무관 견고한 **손실 전략**. 폐기.
- "최근 KOSPI 강세장 전략" 탐색은 포물선 ATH 꼭대기 fitting = 최악의 과적합 함정.
  벤치마크는 0이 아니라 지수 매수보유. 엣지 후보는 신호가 아니라 참여+생존(추세이탈 청산).

## 후속 B — 추세 오버레이 vs 매수보유 (사전등록, 2026-06-02, 결과 보기 전)
질문: 타이밍(추세 오버레이)이 그냥 보유를 이기는가? = 포지셔널-베타 결론 직접 시험.
과거 세션 4-NULL 신호 재탐색 아님(미탐색 각도).

- **자산(단일, 3개)**: KODEX200(069500, 지수프록시), 삼성전자(005930), SK하이닉스(000660).
- **데이터**: KIS 일봉 adjusted 2021-01-01 ~ 2026-06-02 (조정·하락장 포함). period_price 페이징.
- **전략(사전등록, 소수)**: close>SMA(N) → 풀투자, 아니면 현금(0수익). N ∈ {20,50,200}. + 매수보유(벤치).
- **비용**: 전환마다 왕복 35bps(매도세 0.20% 일부 + 슬리피지; 일봉이라 인트라데이보다 낮음).
- **OOS**: train 2021-2023(2022 하락장 포함) / test 2024-2026(멜트업 포함). 둘 다 보고.
- **지표**: 총수익·CAGR·연샤프·MaxDD·시장노출%·거래수. 자산별·구간별.
- **사전등록 판정룰**: 추세 오버레이는 train·test **둘 다**에서 (샤프가 매수보유 초과) 또는
  (CAGR 1/3 이상 포기 없이 MaxDD 1/3 이상 감축) + 최악연도 DD 실제 감소 시에만 "이김".
  아니면 결론 = **그냥 보유**(타이밍 무가치). 한 번만 실행, test에 재튜닝 금지.

## B 결과 (2026-06-02, cost=35bps, split=20240101, 2021-01~2026-06)
⚠️ **버그 수정판**: SMA warmup을 슬라이스마다 재시작하던 버그 수정(overlay를 전체 시계열
1회 계산 후 슬라이스). 수정 전 "지수 통과"는 2024 TEST 시작점 ~200봉 강제현금 artifact였음.
TRAIN은 2021 진짜 시작점 warmup이라 불변. 판정룰 그대로:

| 자산 | TEST(24-26, OOS·멜트업) SMA200 vs 매수보유 | 판정 |
|---|---|---|
| 069500 지수 | Sharpe **2.04 < 2.13**, CAGR 72<84, DD -22.3≈-21.6, 노출74% | ❌ **탈락**(보유 우위) |
| **005930 삼성** | Sharpe **2.01>1.73**, CAGR 103>92, DD **-25 vs -43**, 노출67% | ✅ 통과 |
| 000660 하이닉스 | Sharpe 1.99<2.35, CAGR 156<235, DD -57.7(보유보다 악화) | ❌ 탈락 |
| SMA20/50 전 자산 | 휩쏘 자멸(거래 26~171회), 전부 매수보유 미달 | ❌ |

**결론(수정):**
- warmup 버그 잡으니 **지수 SMA200 통과 소멸.** OOS 통과는 **삼성 1종목뿐**(3중 1) → 견고성
  부족 = 사실상 idiosyncratic. 삼성은 200일 필터가 2024 -43% 폭락을 -25%로 줄임(진짜 OOS).
- 빠른 MA = 휩쏘. 하이닉스 = V자 반등이 MA 휩쏘. **타이밍이 보유를 신뢰성있게 못 이김.**
- **포지셔널 베타 결론 3번째·가장 강한 재확인.** 정직한 takeaway: **그냥 보유.** 굳이 개선하려면
  삼성 한정 200일 추세필터(붕괴 보호) 정도, 그나마 n=1 약세장(2022)·1종목 의존이라 과신 금지.
- 유니버스 = 그 기간 최대 상승 2종목+지수 → trend-on-winners 약한 순환성. "베타다" 프레이밍이 흡수.
